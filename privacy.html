Data and connected accounts

Privacy notice

Last updated 16 October 2026

This notice covers the personal Content Factory 02 application and this informational website. Mohamed Ghali controls the local installation and the content processed through it.

Information used by the application

The operator supplies ideas, source text, media, destination details, edits and approvals. The app uses YouTube API Services. A Google connection may provide channel identification and the metadata, privacy, processing and disclosure fields of the operator’s own uploaded videos.

Approved uploads send the selected media and reviewed title, description, tags and audience settings to YouTube. The app is not a public service for collecting other people’s Google account information.

If the operator connects an Instagram professional account, the initial connection requests basic Instagram access. The identity check reads its account ID and username to identify the intended destination. It does not read messages or comments or publish content. Any later publishing connection needs separately reviewed permissions and content approval.

Why the information is used

Information supports drafting, fact-checking, producing content, identifying the intended destination, recording human decisions, staging approved uploads and checking results. The app keeps operational evidence to resume interrupted work and avoid duplicate uploads.

Google user data is not sold, used to build advertising profiles or used for credit decisions. Access is limited to the connected functions authorized by the operator.

Selected services and sharing

Google and YouTube receive authentication requests and the approved data needed for their connected features. The operator may select an online language or media service for drafting and production. That provider receives the selected ideas, material or public destination details needed for the task and handles them under its own terms and settings.

Instagram and Meta receive requests needed for the operator’s approved Instagram connection. The Instagram login return page is hosted on GitHub Pages. GitHub receives the request for that page, including the short-lived authorization code and connection state when they are present in its URL. The page uses those values in browser memory to return to the operator’s local n8n app at localhost, and removes them from the displayed page address. This return page does not exchange codes for tokens or contain the app’s client secret.

Passwords, OAuth client secrets and access or refresh tokens are not included in editorial agent packets. The operator controls access to the local application and any task-specific access given to an agent or another person.

Local storage and removal

Production media, drafts, review decisions and operational records are stored in the operator’s local workspace. Google and Instagram connection tokens are managed by the local automation credential system, which encrypts its saved credentials. Token exchange runs on the operator’s computer, not on this website. The website code does not write login results to browser storage or send them to an analytics service.

Local data removal is currently handled manually by the operator. This website has no account or deletion dashboard, and the application does not currently provide an automatic deletion schedule. Contact the operator to request removal of information held by the application.

Deleting a local record does not delete a video held by YouTube. Uploaded videos must be managed separately through the relevant platform account.

Your Google access choices

You can review and revoke the app’s access on Google’s security permissions page. Revocation stops authorized access. It does not by itself remove uploaded videos or local production copies; contact the operator about locally retained information.

Google’s own handling of information is described in the Google Privacy Policy. The app’s connected use is subject to the Google API Services User Data Policy, including its Limited Use requirements, and the YouTube API Services Developer Policies.

Instagram access can be reviewed and removed in Instagram’s Apps and websites settings. Removing access does not delete local production records or content already held by a platform. Contact the operator about local information. Meta handles its own service data under its Privacy Policy.

This website

This static site has no analytics scripts, advertising, forms, public account registration or application cookies. Its operator-only Instagram return page is part of the connection flow described above; it does not expose the local editor, production controls or stored credentials to the public. GitHub logs visitor IP addresses for security under its Privacy Statement. External links lead to services with their own policies.

Contact and changes

Contact Mohamed Ghali on Facebook with questions, complaints or a data-removal request. Do not include passwords, access tokens or other secrets in a message.

This page will show a new date when the notice changes. Material changes to data use or permissions need the operator’s review before use.
